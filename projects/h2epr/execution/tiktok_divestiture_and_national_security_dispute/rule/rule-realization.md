# TikTok dispute Rule realization review

## Decision ownership

The realization maps ten exact actor IDs and 23 event intents plus `no_op` to
the maintained declarative Rule engine. Rule owns selection only; semantic
parents own meaning, the environment owns admission/effects, MASim owns
transport/trace order, and publication independently derives evidence.

## Behavior and temporal review

Rows use inclusive windows, sealed public state and actual delivered-message
memory. Mandate, filing, defence, ruling, hearing, testimony, passage, signature,
service response and negotiation positions remain separable. One actor emits at
most one action per coordinate.

## Failure and reproducibility review

Missing information produces waiting/open endpoints. Foreign intents or targets
are typed rejections with no delta. Implementation sources are exact-hashed;
model/network fallback is absent. Fresh A/B, generated-ID perturbation, replay,
graph, seals and independent rematerialization remain release obligations.

## Boundary

Acceptance demonstrates deterministic attachment to one admitted package. It
does not validate legal correctness, security allegations, platform effects,
agreement implementation, historical fit, causality or scientific generality.
