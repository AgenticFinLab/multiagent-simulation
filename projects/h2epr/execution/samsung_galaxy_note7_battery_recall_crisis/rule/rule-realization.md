# Samsung Galaxy Note7 Battery Recall Crisis Rule realization

## Identity and capabilities

This realization binds the exact current Rule configuration and eight current
human parents to `h2epr.backend.rule.declarative.v4`. It pins the four maintained
Rule implementation files. No event-specific Python, model caller, network
access, dependency substitution or MASim edit is used.

Samsung owns manufacturer records; three Populations own aggregate cohort records;
the quality regulator, ATL, airline gate and consortium retain distinct bounded
interfaces. The backend cannot transfer any actor's authority. The SDI source ID
is retained in roster/context and intentionally has no runtime backend.

## Decision production and memory

Rows use inclusive windows, stable IDs and distinct priorities. State and actual
received-memory guards must all match. One row per actor may fire per coordinate;
otherwise `no_op` records waiting. Accepted rows never repeat. A rejected row may
retry only after a changed visible-information fingerprint. Opaque generated IDs
never order decisions.

## Environment and result boundary

The backend emits intents and qualified messages. The environment checks
eligibility/parameters/preconditions; the reducer owns effects, transport owns
delivery and runtime owns memory. Reports do not verify physical cause, recall
notices do not complete returns, a request does not pay a refund, litigation does
not determine liability, and findings/final report remain separate records.

## Failure routing and verdict

Invalid contracts fail admission. Invalid actor/target or unmet prerequisites
produce typed rejected dispositions. Runtime/transport failure retains a sealed
prefix and cannot produce a complete release. Trace, seal, replay, graph or
independent-rematerialization mismatch rejects publication.

Semantic realization is accepted for fresh deterministic verification under the
published full-Draft, representation-gate and sparse-record limits. This is
author self-review; runtime evidence and independent publication are still
required. LLM and RuleLLM remain planned and fail closed.
