# ADR-0016: Note7 Scenario Configuration boundary

- Date: 31 August 2026
- Status: accepted for authoring-window candidate release
- Event: `H2EPR-0481`

## Context

The accepted Scenario requires a small qualitative mechanism-coverage
configuration and exposes two reusable admission issues: cyber-specific
structural slot names and non-institution Population resource domains.

## Decisions

### `OD-0481-CFG-01` — purpose and clock

Use one non-executable mechanism-coverage configuration from 19 August through
15 October 2016. Do not calibrate, validate, or fit a known outcome.

### `OD-0481-CFG-02` — participant assembly

Instantiate four named authority actors and one scoped semantic unit for each
of the four Population Models. Use Singapore only where regional evidence
supports it; treat other unit scopes as mechanism-coverage constructions.

### `OD-0481-CFG-03` — state, inputs, and structure

Use seven typed registry entries, eight resource objects, 34 opening records,
eight exact routes, six domain-neutral structural selections, six non-outcome-
forcing inputs, nine unbound policy meanings, and six paired overlays.

### `OD-0481-CFG-04` — lineage and execution boundary

Select the Samsung--regional--outlet--consumer remedy lineage as the first
semantic slice. Order its last two choices as consumer remedy request followed
by outlet response; response cannot precede the request it cites. Keep every
policy unbound, execution eligibility false, and all carrier projection,
binding, runtime, simulation, and evaluation authority outside the
configuration.

## Shared compatibility decision

Introduce a semantic v0.2 closed schema with a complete domain-neutral six-slot
vocabulary and optional `semantic_kind`. Retain the v0.1 schema, original
SingHealth vocabulary, document bytes, receipt, and all descendant identities
unchanged. The shared validator dispatches by explicit format identity. This
is a configuration admission generalization, not a Contracts V1 change.

## Consequences

The exact configuration may proceed to static fail-closed admission. Review is
authoring-exposed; the original max supervisor remains the independent final
reviewer.
