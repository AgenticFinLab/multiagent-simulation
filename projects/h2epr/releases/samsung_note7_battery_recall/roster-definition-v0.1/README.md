# Samsung Galaxy Note7 Roster Definition release v0.1

- Status: accepted semantic release
- Event: `H2EPR-0481`
- Roster: `v0.1`
- Released: 31 August 2026

This release closes the H2EPR-0481 participant-definition phase. It pins four
Agent Definitions, four Population Models, the accepted research roster and
event semantic skeleton, two evidence authorities, and one shared participant
interface.

## What the release establishes

Every causal row has a reviewed disposition:

- four authority-bearing Agent interfaces own the Samsung, CPSC, CAAC, and
  U.S. DOT issuance choices without becoming whole-organization minds;
- four heterogeneous populations own evidence-supported regional,
  intermediary, consumer, and transport-operator choices without collective
  knowledge or authority;
- suppliers remain deferred investigation context, while devices and incident
  arrivals remain exogenous or Scenario-owned processes;
- the two transport lifecycles remain separate institutional processes that
  begin only after valid authority-specific issuance; and
- media, litigation, liability, market, environmental, return-rate, and later
  remediation outcomes remain excluded context or aftermath.

The release is a qualitative semantic research input. It is not an executable
participant bundle, Scenario, mapping, configuration, simulation, historical
calibration, effectiveness result, or scientific-validity claim.

## Later event work

A later phase may construct one consolidated semantic mapping and one Event
Scenario Definition from this exact inventory. That work must preserve
participant-time information, organization and jurisdiction boundaries,
unit-local population state, issuance/lifecycle separation, and the
intent-to-result boundary. It may not silently introduce a supplier Agent,
merge CAAC with U.S. authority, or treat public posting as universal receipt.

This release does not itself authorize configuration, implementation,
simulation, generated-graph work, calibration, or evaluation.
