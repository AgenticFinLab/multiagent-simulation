# Panic of 1907 Scenario release

The ten-module Scenario owns a sparse institutional and reform-record world. Its
interface declares 23 fields, 23 typed event intents plus `no_op`, explicit
information routes and seven trace-derived annotations.

Prices, balances, payments, solvency, recovery, votes and policy effectiveness
remain outside the reducer. Expectations describe the canonical Rule baseline;
integrity and terminal transport control publication. Human and machine owners
are sealed together.
