# Lebanese Civil War Scenario release

The ten-module Scenario owns a sparse 1975–1990 public-record world. Its
interface declares 33 fields, 33 event intents plus `no_op`, explicit
information routes and eight trace-derived annotations.

Combat, civilians, casualties, territory, weapons, aid, responsibility,
constitutional implementation and peace effectiveness remain outside the
reducer. Expectations are descriptive; integrity and terminal transport control
release.
