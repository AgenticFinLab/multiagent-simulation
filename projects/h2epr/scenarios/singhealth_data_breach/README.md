# SingHealth Data Breach Scenario release

The ten-module Scenario owns a sparse incident-response and public-record world.
Its interface declares 17 record fields, 17 typed event intents plus `no_op`,
explicit information routes and six trace-derived annotations.

Technical compromise, individual notification/harm, fine payment, completed
remediation, effectiveness and attribution truth remain outside the reducer.
Expectations describe the canonical Rule baseline; integrity and terminal
transport control publication. Human and machine owners are sealed together.
