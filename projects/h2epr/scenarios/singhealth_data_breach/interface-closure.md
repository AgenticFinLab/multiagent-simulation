# SingHealth Data Breach interface closure

The scenario closes the roster, actor map, semantic parents, observation and intent registries, lifecycle registry, typed state fields, handlers, routes, timeline, and Rule decision rows over the same active actor universe.

Admission is independently recomputed by the compiler. Human prose does not override the JSON contracts. `no_op` is available to every actor; every non-`no_op` intent is exercised by at least one published Rule row. Messages cannot write state directly and all routes are explicit.

The closure is dataset-conditioned because `draft_epg` is fully exposed. It supports deterministic construction, validation, replay, and trace-derived graph publication; it does not support historical fit or scientific evaluation.
