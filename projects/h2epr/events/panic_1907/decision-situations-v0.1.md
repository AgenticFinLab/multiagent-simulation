# H2EPR-0288 decision-situation portfolio

This portfolio organizes the shared situations used to review the two current Agent Definitions. It is a
research companion rather than a scenario configuration or executable policy. Claim identifiers resolve in
the [participant-evidence record](participant-evidence-v0.1.md).

## 1. Purpose

共享 portfolio 用同一事件链检查两个角色的差异是否来自 institution、information、authority、
resource control、procedure 和 persistent state，而不是名字、allowlist 或一组任意阈值。

它比冻结的三步工程基线更丰富，但仍围绕一个事件边界。每一情境都应由研究证据决定保留、合并、拆分
或删除；不会因为列在这里就自动成为 Agent 的行为规则。

## 2. Event sequence and research questions

### S0 — Pre-request institutional baseline

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| research question | ordinary governance、liquidity monitoring、clearing dependence 如何运行？ | member/nonmember clearing、examination、reporting、reserve 与 privilege rules 如何运行？ |
| value | 防止 Agent 只在已知 crisis trigger 下存在 | 防止从 10 月 21 日 refusal 反推整套制度 |
| critical evidence | corporate roles、statements、banking rules、clearing relation | constitution/bylaws、approvals、committee/practice records |

### S1 — Pressure becomes behaviorally relevant

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| legal observation question | 管理层实际看到什么提款/现金/clearing information？ | 哪些 member/system or counterparty signals 当时合法可得？ |
| behavioral question | 哪些 ordinary action、information seeking 或 escalation 被触发？ | 是否尚无可处理 request；public pressure 是否真的进入任何 decision？ |
| falsifier | 只因历史日期/actor ID 就进入求援分支 | 无请求也自动输出 rescue/refusal |

### S2 — Internal authorization and channel formation

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| governance question | 谁可授权求援、提供资料、承诺 collateral 或改变 operations？ | 尚未收到 request 时，NYCH 是否有主动 role；依据是什么？ |
| relationship question | NBC channel 如何形成、确认、改变或失效？ | 何时知道 requester/channel/representation 合法？ |
| structural unknown | exact representative and mandate (`KT-C13`) | unsolicited/proactive authority 未研究 |

### S3 — Request delivery and classification

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| state | request sent/delivered 仍不是 accepted/realized | receipt 触发 identity、membership、route、information、authority classification |
| decision question | 是否等待、补资料、确认状态或并行考虑其他有证据的 route？ | 哪些分类是 hard institutional fact，哪些需 review/interpretation？ |
| critical distinction | transport status vs business result | member-facility gate vs other-route authority unknown |

### S4 — Information, review, and authorization incomplete

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| missing information | 不得读取 NYCH deliberation、global resources 或未送达结果 | 不得读取隐藏 solvency、future suspension 或全局精确 member states |
| candidate behavior | provide/request information、confirm channel/status、wait、escalate、abstain | request information、open/continue review、seek authority、refer、communicate status、abstain |
| research need | 哪些 alternatives 真实存在且谁能授权？ | exact review/committee procedure 和所需材料是什么？ |

### S5 — Route, eligibility, discretion, and collective resources

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| known boundary | nonmember；member facility 不适格 | must enforce member-facility boundary |
| unresolved structure | 还有哪些有证据支持的 indirect/other routes？ | other-route evidence and bounded discretion (`NYCH-C13`) |
| resource question | 能控制、承诺、抵押或仅请求什么？ | NYCH、committee 和 member banks 各自控制什么？ |
| mechanism test | relationship-dependent options 是否真实改变 behavior？ | hard protocol、member priority、resource stewardship、solvency assessment 如何区分？ |

### S6 — Intent, adjudication, and delivery

| Dimension | Knickerbocker | NYCH |
|---|---|---|
| output | request、information、communication、operational preparation or abstention | review、information request、referral、typed decline、authorized proposal、communication or abstention |
| forbidden outcome | support obtained、institution stabilized/closed | resources transferred、requester rescued、system stabilized |
| environment role | route delivery、eligibility、feasibility、result、state transition | authority validation、member/resource conflicts、execution、partial/failure/result delivery |

### S7 — Delivered result and adaptive response

| Result class | Knickerbocker research question | NYCH research question |
|---|---|---|
| delayed/pending | request strategy、information、operations 如何变化？ | review/authorization/resource state 如何推进？ |
| denied/prohibited | 是否考虑有证据的 alternative route、communication、operational response？ | reason type、authority 和 communication 如何形成？ |
| partial/no effect/failed | 机构如何辨别并更新 private decision state？ | 是否需 follow-up、reconsideration、resource or member coordination？ |
| executed | 只有 delivery 后才更新；不能提前自证 | execution 是 environment result，不是 NYCH intent |

### S8 — Representation and mechanism perturbations

1. Actor-name erasure：更换名称但保留语义，行为不应变化。
2. Authority swap：交换 institutional authority，合法 intent envelope 应结构性变化。
3. Information masking：删除/延迟 required information，应产生已声明 fallback。
4. Pending lifecycle：unresolved request 不应每 tick 被当作新业务。
5. Route-evidence/discretion fork：固定 member-facility 边界，比较“无已确认替代路线”基线与有边界的替代路线裁量，不用 probability 混合。
6. Aggregate/split NYCH：只有内部 actors 增加可检验解释力时才拆分。
7. Aggregate/split Knickerbocker：只有 board/officer conflict 影响 focal process 时才拆分。
8. Intent/result ladder：合法 intent 可以 delayed、partial、failed 或 no effect。

## 3. Cross-role research matrix

| Research dimension | Shared standard | Expected legitimate difference |
|---|---|---|
| evidence | claim-level source/time/use/exposure | source richness and uncertainty may differ |
| representation | explicit decision interface and split trigger | trust company vs association governance |
| observation | participant-time legality and missing behavior | internal financial view vs request/procedure/member view |
| private state | behaviorally necessary, legitimate updates | operational/request posture vs review/authorization/resource commitment |
| authority | explicit jurisdiction and procedure | requester/self-operations vs collective facility/coordination |
| mechanism | theory + event applicability + alternative | liquidity/relationship response vs institutional/collective process |
| intent | domain-level attempt, no result ownership | request/operations vs review/referral/decline/proposal |
| uncertainty | no invented precision | different structural gaps |
| falsifier | role, information, state, mechanism perturbations | participant-specific forbidden patterns |

## 4. Selection rule for current and successor Definitions

保留一个 decision situation，至少应满足一项：

- 引入独立 governance/authority boundary；
- 引入独立 information or private-state problem；
- 区分 competing behavioral mechanisms；
- 支持一个新的 domain intent or fallback；
- 产生不同且可反驳的 process prediction；
- 暴露 aggregate representation 的不足。

仅重复同一压力阈值或已知结果的情境应合并。最终示例数由证据和解释需要决定，不以当前 S0–S8 数量
作为格式要求。
