# Phase-0 baseline

V1 freezes the contracts needed before any event runtime is implemented:

- four construction identities and irreversible contamination propagation;
- strict prefix projection attestation and source allowlists;
- typed construction-to-evaluation lineage;
- agent intention versus environment disposition versus committed world effect;
- single-recipient canary transport with deterministic fan-out adaptation;
- logical tick closure, canonical hashes, TickSeal and RunSeal;
- auditable versus compiler/evaluator-eligible traces;
- Generated EPG foreign-key and provenance closure; and
- evaluation-only access to held-out real-process references.

The baseline does not freeze an H2EPR-0288 `t0`, participant roster, or a
production tick-barrier implementation. It also does not authorize runtime
code, experiments, fidelity claims, counterfactual studies, model policies, or
human-substitutability claims.

The synthetic external construction anchor proves the validation interface. It
is not an approved production lineage root and cannot substitute for a later
frozen allowlist/review context.
