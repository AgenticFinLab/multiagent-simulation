# Agent Definition review

Read [references/guide.md](references/guide.md) for the independent review
record, severity model, adversarial probes, finding format, and routing rules.

## Inputs

Review the exact candidate, Source Profile, roster/actor map, shared registries,
Scenario Definition candidate, template, and publication standard. Do not
expand the evidence boundary.

## Review passes

1. **Representation:** identity, decision interface, aggregation, omissions,
   and successor condition are explicit.
2. **Dataset provenance:** material claims resolve to allowed records;
   assumptions and generated observations are not presented as source facts.
3. **Information and state:** every observation and persistent item has one
   owner, availability rule, consumer, and missing behavior.
4. **Authority and result:** intents remain inside authority; environment owns
   delivery, admission, feasibility, effects, and success.
5. **Backend neutrality:** no exact Rule thresholds, model prompt wording,
   decoding, fallback, or successful trajectory appears in the Definition.
6. **Behavioral substance:** activated situations constrain response and do
   not admit indefinite always-abstain behavior.
7. **Adversarial cases:** name erasure, role swap, future injection, missing
   information, invalid intent, pending state, authority denial, adverse
   environment result, meaningful perturbation, and aggregation change. An
   Agent Definition must not contain population-only claims about distributions
   or microdata.
8. **Publication:** natural prose, stable modules, exact semantic IDs, concise
   limitations, and no build diary.

## Verdict

Use `accept`, `accept with recorded limitations`, or `return to owning layer`.
List findings by severity and name the exact owner of each correction.
