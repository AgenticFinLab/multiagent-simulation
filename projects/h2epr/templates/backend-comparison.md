# Backend comparison template

Compare only runs with identical backend-neutral package identity, shared
configuration, runtime, environment, trace contract, and compiler.

## Compared runs

List backend, binding/realization identity, model settings or Rule version,
seed, run, trace, replay, and graph identities.

## Comparable process differences

Compare decision frequency, action and message mix, invalid or rejected
intents, delays, resource outcomes, state trajectories, terminal state,
lifecycles, generated stages, and observed variation. Attribute each difference
to decision production only when the parity checks pass.

## Interpretation boundary

Do not infer historical fidelity, policy effectiveness, model superiority, or
scientific validity from an engineering comparison. Record alternative
explanations and missing evaluation protocol.
