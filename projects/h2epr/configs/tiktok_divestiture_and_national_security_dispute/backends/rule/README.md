# TikTok dispute Rule configuration

Twenty-three guarded rows select bounded executive, litigation, oversight,
legislative, judicial, platform and negotiation records. Inclusive windows
permit waiting for actual information; accepted rows finish once and unchanged
rejection cannot create a retry. `no_op` is the explicit fallback.

All six top-level settings have provenance. Rule cannot decide legal validity,
security, user impact, data/algorithm control, ownership or implementation.
