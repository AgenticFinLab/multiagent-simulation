# SingHealth Data Breach comparison configuration design

The shared configuration fixes the actor universe, logical coordinate order, typed initial state, explicit communication routes, observation boundary, and termination behavior for backend comparison. Values are classified as dataset-derived or structural in the machine-readable provenance table.

Full Draft exposure permits deterministic construction practice but excludes held-out evaluation. Rule is implemented; LLM and RuleLLM remain planned and cannot be selected by the package loader.

Every top-level shared setting is now closed by explicit provenance; this release uses no exemptions.
