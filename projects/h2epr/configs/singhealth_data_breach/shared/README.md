# SingHealth Data Breach — Shared comparison configuration

## Authority

The configuration fixes backend-neutral selections and publishes an independently checked, exhaustive top-level provenance map. Any uncovered value fails compilation.

## Evidence and failure routing

`manifest.json` pins every artifact, semantic parent, role, size, and content
hash. `SHA256SUMS` is the exact local publication surface. Schema, identity,
parent, path, coverage, or checksum drift rejects admission; correction
requires another successor.
