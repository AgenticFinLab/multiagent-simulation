# Baoneng–Vanke Takeover Battle Rule configuration

Twenty-seven state/received-memory guarded rows select participant disclosures,
positions, requests and institutional records within inclusive availability
windows. One no-op fallback handles waiting, completed rows and closed windows.
The six top-level settings have complete provenance and no exemptions.

The backend owns selection and statement production only. It cannot execute
share transfers, appoint directors or alter shared environment state. Changed
choices require re-admission and a rebuilt binding/run, never edits to sealed
runtime evidence.
