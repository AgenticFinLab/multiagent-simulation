# Samsung Galaxy Note7 Battery Recall Crisis Rule configuration

Twenty-eight guarded rows select bounded participant reports, statements,
requirements, requests, product decisions and investigation records. Inclusive
windows permit waiting on actual information; accepted rows finish once and
unchanged rejection cannot create a retry. `no_op` is the explicit fallback.

All six top-level settings have provenance. The Rule cannot create physical
fires, completed returns, findings for another actor or court outcomes. Any
choice change requires re-admission and rebuilt evidence.
