# Samsung Galaxy Note7 Battery Recall Crisis Scenario Configuration

## Identity and purpose

Shared configuration `h2epr.0481.comparison.v1` selects one dataset-conditioned process
baseline; `h2epr.0481.rule.v1` owns deterministic participant choices. This is a
construction and reproducibility baseline, not an admitted scientific experiment,
historical reconstruction or tuned crisis-response policy.

## Exact parent boundary

The assembly pins the Source Profile, complete roster/map, eight human parents,
participant interface, Scenario and configuration releases. Environment and
annotation implementations are the maintained declarative versions. The Rule
realization pins common implementation-source hashes; no event-specific runtime
code or MASim modification exists.

## Rule settings and behavioral use

The Rule configuration contains 28 ordered rows, inclusive windows, explicit
state and delivered-message guards, one-action-per-actor cadence and `no_op`
fallback. Accepted rows complete once. Rejected rows reopen only after changed
visible information. Participant memory contains actual receipts and own
dispositions, never source-stage omniscience.

The selected content is sparse: reports, notices, statements, requirements,
requests and investigation records. No alternative recall scope, physical-event
probability, utility, compliance propensity, legal strategy or supplier policy
is fitted. Richer choices require parent successors before backend tuning.

## Variants, verification, and failure routing

The required construction variants remove a domestic report or delay independent
findings through freshly admitted configuration/package successors. They may
produce open expected endpoints and still be valid when trace, replay, graph and
transport close. They are not cross-backend experiments.

Malformed paths, schema, parents, actor/intent/field coverage, provenance or
backend identity fail compilation. Wrong actor/target and failed preconditions
produce typed rejected dispositions. Runtime failure retains attempt evidence;
publication rederives evidence and cannot trust a producer success boolean.
Changing meaning routes to semantic parents; changing windows/routes routes to
configuration; changing code requires a generic reduced test.
