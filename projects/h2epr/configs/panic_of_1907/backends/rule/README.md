# Panic of 1907 Rule configuration

Twenty-three guarded rows select bounded scheme, withdrawal, aid, support,
containment, aggregate-flow and reform records. Inclusive windows permit waiting
for actual information; accepted rows finish once and unchanged rejection cannot
create a retry. `no_op` is the explicit fallback.

All six top-level settings have provenance. Rule cannot simulate markets,
balance sheets, transfers, votes, recovery or policy effects. Choice changes
require re-admission and rebuilt evidence.
