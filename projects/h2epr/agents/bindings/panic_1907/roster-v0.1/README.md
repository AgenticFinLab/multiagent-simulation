# Panic of 1907 roster mapping profile

This directory contains the executable, conformance-only projection of the
accepted Roster Definition release and consolidated mapping design.

`mapping-profile.json` references the two accepted manifests by hash. The
loader also verifies the accepted mapping artifacts, owner decision, release
checksum file and all twelve released semantic products before deriving their
commitments, observations and intents from the frozen Markdown files. It does
not treat the non-executable inventory as a substitute source.

The embedded fixture is synthetic. It checks three carrier risks identified by
the accepted V1 review:

- one institution composes bank-resource and call-money-lender capabilities
  while retaining one actor, authority graph and resource owner;
- one depositor unit keeps a private observation scoped to its host and choice
  unit; and
- one broker funding case keeps action admission, business result, delivery,
  object version and replay identity separate.

The profile derives carrier identities; it does not define the complete
parameter contract for every intent or observation. It does not select a Rule
policy, create a runnable historical scenario, start a simulator, or claim that
the fixture describes the historical path. The earlier two-role binding
remains the frozen engineering reference.
