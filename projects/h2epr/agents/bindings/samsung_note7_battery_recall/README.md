# Samsung Galaxy Note7 Battery Recall bindings

This directory contains the release-wide mapping and bounded carrier binding
for H2EPR-0481:

- [`consolidated/`](consolidated/) maps all eight released products and every
  semantic placement without implementing behavior.
- [`samsung-regional-outlet-consumer-v0.1/`](samsung-regional-outlet-consumer-v0.1/)
  projects seven accepted intents across one Samsung crisis interface, one
  regional unit, one outlet unit, and one consumer choice unit.

The bounded binding does not implement the other four actors or thirty intent
placements. It starts no simulator and establishes no calibration, historical
fit, policy effectiveness, or scientific validity.
