# Baoneng–Vanke Takeover Battle participant interfaces

Eight Agent Definitions are the human semantic parents. The semantic index seals
their exact paths, hashes and source anchors. This release projects eight actors,
four runtime-produced observation classes, 27 event intents plus `no_op`, and
two lifecycles. There is no omitted Population interface: the roster requires none.

Intent eligibility keeps personal statements, shareholder positions, the
corporate board-response record and regulatory guidance separate. All actors
decide from the same sealed prestate; memory contains actual receipts and own
dispositions. Pending incoming private content and future stage text are absent.
The registry does not give a message recipient state-write or election authority.

Actor/intent drift routes to the parent and this projection before compilation.
Changed parents require rebuilt hashes and dependent configuration/release
identities, not a patched package checksum.
