# SingHealth Data Breach Agent Definitions

This directory contains seven office-level Agent Definitions for the
SingHealth Data Breach.

Detection and escalation:

- [Security Incident Response Manager](security-incident-response-manager.md);
  and
- [Cluster Information Security Officer for SingHealth](cluster-information-security-officer.md).

Classification and institutional escalation:

- [SingHealth Group Chief Information Officer](singhealth-group-chief-information-officer.md);
- [IHiS Cyber Security Governance Director and healthcare Sector Lead](cyber-security-governance-director-and-healthcare-sector-lead.md);
- [IHiS Chief Executive Officer](ihis-chief-executive-officer.md);
- [SingHealth Deputy Group Chief Executive Officer for organisational transformation and informatics](singhealth-deputy-group-chief-executive-officer.md);
  and
- [SingHealth Group Chief Executive Officer](singhealth-group-chief-executive-officer.md).

Two adjacent Population Models preserve distributed choices without creating
collective organizational Agents:

- [technical administration and line security staff](../../../populations/defines/singhealth_data_breach/technical-administration-and-line-security-staff.md);
  and
- [IHiS operational and SCM management](../../../populations/defines/singhealth_data_breach/ihis-operational-and-scm-management.md).

The shared [participant-evidence record](../../../events/singhealth_data_breach/participant-evidence-v0.1.md)
contains the adopted participant claims. The
[detection-and-escalation](../../interfaces/singhealth_data_breach/r1-detection-and-escalation.md)
and
[classification-and-institutional-escalation](../../interfaces/singhealth_data_breach/r2-classification-and-institutional-escalation.md)
accounts compare the models' information, authority, intent, lifecycle, and
result semantics.

The Definitions and Population Models are qualitative and event-bound. The
complete historical outcome informed construction, so their worked cases
provide explanatory and falsifying surfaces rather than independent
validation.
