# 00 · 概念澄清（I10 价值位定位 · I1 活跃子集 / 抽样）

> 用大白话把两个被问到的概念讲清楚，并落到金融模拟的具体例子。

## 1. 「价值位定位」是什么意思（对应 I10）

**价值位定位 = 回答一个问题：在这张“已有工作地图”上，还空着的那个格子是什么？我们打算站上去。**

- “定位”就是一句话说清楚：**我们做的东西，别人没做或没做全，为什么值得做。**
- “价值位”就是地图上的那个**空位**。

打个比方：

```text
把“多智能体模拟”想象成一张地图，横轴是「世界侧（环境/市场/时间）↔ 能力侧（编排/协议/治理）」，
纵轴是「规模（几十 ↔ 几十万）」。

现有系统各自占了一块：
  OASIS / AgentSociety  —— 占了「大规模 + 社会世界」
  MarketSim / TwinMarket —— 占了「金融世界 + 中等规模」
  AutoGen / LangGraph   —— 占了「小规模 + 高质量协作」
  MAF                   —— 占了「能力侧 + 协议/治理」
  MASim（我们）          —— 占了「金融世界 + 分布式 + 四机制」

而「金融世界 + 标准协议互操作 + 从几十到几十万的异构降级」这个交叉格子，
没有任何一个现有系统完整占住。
```

所以 I10 说的“价值位”就是：**这个交叉格子**。把它作为本项目的定位，就是：

> 做一个“金融世界的混合多智能体运行时”：世界内核负责市场/时间/拓扑，MAF 负责标准协议与编排，规模上靠“异构引擎 + 分层 + 降级”从几十一直撑到几十万。

**一句话回答“我们是谁”**：别人要么会“跑世界”但不会“标准互操作”、要么会“编排”但不会“大规模世界”；我们把两者合起来，并补上规模降级。

## 2. 「活跃子集」和「抽样」是什么意思（对应 I1）

I1 说“规模越大，LLM 占比越低”。怎么做到“低占比”又不损失太多真实感？两个具体手段：

### 2.1 活跃子集（active subset）

**不是每个 agent 每轮都需要“思考”**。大多数 agent 在大多数轮次里“没什么新信息”，沿用上一轮策略即可。

- 活跃子集 = **这一轮真正需要做一次 LLM 决策的那一小撮 agent**。
- 其余 agent：不调 LLM，用规则/上一轮决策继续。

金融例子：

```text
10 万个投资者，某轮只有 2000 个被触发“需要重新思考”：
  - 遭遇重大价格异动/跳空
  - 收到新的新闻/政策/研报
  - 持仓触及止损/止盈阈值
  - 被抽中做定期复盘

其余 98000 个：继续按既有策略/规则行动，不调 LLM。
```

判断“谁活跃”用**事件驱动 + 阈值规则**，很便宜。

### 2.2 抽样（sampling）

**即使该“思考”的 agent 很多，也只对其中一部分真正调 LLM，用这部分代表全体。**

- 抽样方式：
  - 均匀随机（uniform）；
  - 重要性抽样（importance，按持仓规模/影响力/异常度加权）；
  - 分层抽样（stratified，每个子群体各抽若干，保证覆盖）。

- 没被抽中的 agent：用**规则跟随**，或者**复用一个抽样 agent 的决策分布**。

金融例子：

```text
10 万个散户投资者，本轮有 2 万个“该思考”。
我们只抽 500 个（按持仓规模 + 情绪敏感度重要性加权）真正调 LLM。

这 500 个的决策 → 统计成“意图分布”（比如 30% 看多加仓、40% 观望、30% 减仓）
→ 其余 19500 个散户按该分布用规则方式执行（并加个体噪声）。
```

### 2.3 两者关系

```text
全量 LLM（L1 几十）  ──>  活跃子集（L2 几千）  ──>  活跃子集 + 抽样（L3 几十万）
                          “只有该想的才想”        “该想的也只抽代表”
```

一句话：**先决定“谁需要想”（活跃子集），再决定“需要想的人里只让谁真的想”（抽样）。**

## 3. 落到规模档

| 规模档 | 活跃子集 | 抽样 | LLM 调用量级 |
|--------|----------|------|--------------|
| L1 几十 | 基本全体 | 不抽样 | ~N |
| L2 几千 | 事件/阈值触发的一部分 | 可抽可不抽 | 远小于 N |
| L3 几十万 | 少数事件触发者 + 分层 leader | 必抽 | 常数~数千 |
