# 08 · “异步 LLM 预取”的正确含义（修正版）

> 回应讨论点 3（修正）：**agent 没有第 t 轮观察，就不可能做第 t 轮决策。** 之前“投机预取（预测状态）”的说法是错的，已撤回。
> 正确机制不是“预测未来”，而是 **“低频决策 + 高频执行 + 异步刷新（陈旧容忍）”**。
>
> ⚠️ 注意：这属于**使用者可选的 agent 策略**，不是平台写死的机制。平台只定义「时钟 + 信号 + 同步策略接口」，等待/异步/陈旧均由使用者配置（见 `09-clock-signal-and-sync.md`）。

## 1. 一条铁律

**agent 的决策，永远基于“它做决策那一刻已经看到的观察”。**

- 不可能基于“还不存在的第 t 轮观察”决策。
- 所以任何“提前预测第 t 轮状态去决策”的设计都不成立，删掉。

## 2. 那“异步”到底是什么意思

**“异步” = 把“慢的 LLM 决策”从“世界推进/执行的关键路径”上解耦，而不是“预测未来”。**

关键手法是：**决策频率 ≠ 执行频率。**

- LLM 以**低频**做决策（每 N 轮 / 每天 / 每事件），决策时**它确实看得到那一刻的真实观察**。
- 决策产出一个**“意图/策略”**，之后若干轮由**规则执行器**按这个意图机械执行，**执行不需要 LLM，也不需要重新决策**。

## 3. 具体场景（正确版）

**价值投资者，每 20 轮决策一次：**

```text
第 1 轮：agent 看到第 1 轮的真实观察（价格/持仓/消息）
        → 调 LLM → 产出未来 20 轮的“意图”：
          “逢低分批加仓科技股，单次 ≤5% 仓位，跌破 -8% 止损”

第 2~20 轮：不调 LLM，规则执行器按这条意图机械执行
           （价格到了就买、破位就止损）

第 21 轮：agent 看到第 21 轮的真实观察 → 再调 LLM 刷新意图
        → 第 22~40 轮继续规则执行 ……
```

- LLM **每一处决策都有观察**（第 1、21、41… 轮的真实状态）。
- 中间 20 轮“不思考”，只是“执行上一次的意图”。

## 4. “异步刷新”是怎么做到世界不等 LLM 的

当 LLM 在“后台”算新意图时，世界不必停下来等：

```text
第 20 轮：agent 一边用“第 1 轮的老意图”执行第 20 轮，
          一边基于“第 20 轮的真实观察”在后台提交 LLM（算新意图）。

第 21 轮：新意图算好了 → 换用新意图；
          还没算好 → 继续用老意图（容忍“意图略微陈旧”），到点再降级。
```

- 这就是“异步”：**执行用“最近一次已就绪的意图”，刷新在后台进行。**
- 世界推进永远不被 LLM 卡住，因为执行走的是规则，不依赖正在算的 LLM。

## 5. 三种合法形式（都有观察）

| 形式 | LLM 何时决策 | 决策依据 | 执行 |
|------|--------------|----------|------|
| 低频意图 + 高频执行 | 每 N 轮 | 当时真实观察 | 规则执行意图 |
| 流水线刷新（异步） | 后台持续刷新 | 最新已就绪观察 | 旧意图 + 新意图切换 |
| 事件驱动 | 事件发生才决策 | 事件时的观察 | 规则执行 |

**三者共同点：决策时一定有观察；执行时用“已就绪的意图”，不预测未来。**

## 6. 明确撤回

- ❌ “投机预取：用预估的第 t 轮状态提前提交 LLM”——**错误，撤回**（没有观察不能决策）。
- ✅ 正确说法：**低频决策 + 高频执行 + 异步刷新 + 陈旧容忍**。
