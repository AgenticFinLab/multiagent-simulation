# LTCMCollapse Rule — Analysis Documentation

## §1 Analysis Objectives

This variant implements the deterministic baseline described in `../analysis-bases.md`. Its analysis output is generated by `analysis.py` and is used as the base implementation imported by LLM-family variants.

## §2 Metric To Function Mapping

| Metric | analysis-bases Ref | Function | Current Output Field |
|---|---|---|---|
| Price deviation | `§2.1` | `calculate_metrics(data)` | `deviation_metrics.max_deviation_pct` |
| Maximum drawdown proxy | `§2.2` | `calculate_metrics(data)` | `price_metrics.max_drawdown_pct` |
| Mean absolute deviation | `§2.3` | `calculate_metrics(data)` | `deviation_metrics.mean_deviation_pct` |
| Volatility | `§2.4` | `calculate_metrics(data)` | `volatility.annualized_pct` |
| Price trough | `§2.5` | `calculate_metrics(data)` | `price_metrics.min` |
| Final recovery | `§2.6` | `calculate_metrics(data)` | `price_metrics.final` |
| LLM output quality | `§2.7` | external audit | not applicable to Rule |

## §3 Variant-Specific Notes

Rule analysis has no LLM quality component. Its main responsibility is to verify that deterministic order rules produce a visible dislocation and recovery path in the price series.

## §4 Expected Ranges

| Metric | Expected Pattern |
|---|---|
| max deviation | visibly above normal random-noise band |
| volatility | elevated during stress phase |
| final price | partial recovery toward fundamental |
| price trough | below initial price if stress develops |

## §5 Output Files

| Output | Generated By | Purpose |
|---|---|---|
| `ltcmcollapse_analysis.png` | `create_visualizations()` | 4-panel plot |
| `metrics.json` | `main()` | machine-readable metrics |

## §6 Cross-Variant Comparison

The Rule output is the comparison baseline for LLM, RuleLLM, and Rag. Changes in API-mode timing or intensity should be interpreted relative to this deterministic baseline.
