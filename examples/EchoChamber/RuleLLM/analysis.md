## §4 Variant-Specific Observable Phenomena

RuleLLM is the hybrid variant: an explicit `== DECISION RULES ==` block is
inserted into every prompt while the LLM still supplies the natural-language
reasoning. Analysis should verify that hard rules constrain action selection
but do not fully suppress LLM-driven variance.

| Phenomenon | How to Observe | Contrast with Baseline |
|---|---|---|
| Rule-constrained action distribution | `summary.json → metrics.activity.total_polarize_events` / `total_depolarize_events` stay in the same order of magnitude as Rule | Narrower band than pure LLM; wider than Rule |
| Formula-anchored polarization ramp | `01_echochamber_dynamics.png` (Panel 1) tracks the Rule curve within ±0.05 for most rounds | LLM curve deviates further; Rule is exact |
| Bounded cluster separation | `01_echochamber_dynamics.png` (Panel 2) `cluster_separation` peak within ±10% of Rule's peak | LLM peak can be 20–30% off |
| Preserved schema validity | `compute_api_quality(actions, [])` reports `valid_action_rate ≥ 0.95` | LLM without rules may drop to ~0.80–0.90 |
| Reasoning-driven residual jitter | Panel 3 activity bars show small round-to-round variation even where Rule bars are constant | Rule has no jitter; LLM has more |

RuleLLM is expected to sit between Rule (deterministic) and LLM
(persona-only) on every observed statistic — this is the defining variant
signature.

## §5 Scaling and Sensitivity Analysis

### Round Scaling

| Total Rounds | Expected Observable | Phenomenon Clarity | Recommended for |
|---|---|---|---|
| 100 | Reinforcement + early cluster formation | Low — LLM stochastic tail not averaged out | Quick sanity check |
| 200 | Full arc; rule anchoring visible against LLM jitter | Medium | Standard runs |
| 500 | Statistical convergence of `polarization_persistence`; stable comparison with Rule | High | Rule-vs-LLM contrast studies |

### Agent Count Scaling

| Agent Count | Expected Observable | Environment Dynamics |
|---|---|---|
| Minimum viable (~10) | Rule constraint visible on aggregate but per-agent LLM variance dominates | Small-sample LLM noise dominates |
| Recommended (30–50) | Clean central tendency around Rule with visible LLM residual | Population averages stabilize |
| Large (100+) | Very tight adherence to Rule mean; LLM cost grows linearly | LLM API cost becomes limiting |

### Parameter Sensitivity (Variant-Specific)

| Parameter | Change | Expected Effect on This Variant's Analysis |
|---|---|---|
| Rule-block strictness (`== DECISION RULES ==` verbosity) | +50% verbosity | RuleLLM curve pulled closer to Rule; `valid_action_rate` → 1.0 |
| Rule-block strictness | −50% verbosity | Curve drifts toward LLM; more schema violations |
| Polarizing-role population share | +50% | Amplification rises in step with Rule; residual jitter roughly constant |
| LLM temperature | +50% | Higher round-to-round jitter in Panel 3; `polarization_persistence` variance grows |
| LLM temperature | −50% | RuleLLM converges toward Rule almost exactly |
