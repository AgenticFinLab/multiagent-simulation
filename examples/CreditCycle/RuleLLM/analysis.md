# Credit Cycle RuleLLM Analysis Plan

## §1 Objectives

This analysis checks whether the RuleLLM variant produces a complete, analyzable Credit Cycle trajectory. It maps recorded price, fundamental, and volume series to the metric catalogue in `analysis-bases.md` and supports cross-variant comparison against the Rule baseline.

## §2 Core Metrics

| Metric | Function Contract | Source |
|---|---|---|
| Leverage Amplitude Index | `_compute_leverage_amplitude_index(peak, trough) -> float` | `analysis-bases.md §2.1` |
| Minsky Fragility Score | `_compute_minsky_fragility_score(investor_payloads, prices_list, fundamental, crisis_threshold=-0.05) -> float` | `analysis-bases.md §2.2` |
| Credit Contraction Speed | `_compute_credit_contraction_speed(prices_list) -> float` | `analysis-bases.md §2.3` |
| Counter-Cyclical Offset Ratio | `_compute_counter_cyclical_offset_ratio(investor_payloads, prices_list, fundamental, bust_threshold=-0.05) -> float` | `analysis-bases.md §2.4` |
| Phase Duration Ratio | `_compute_phase_duration_ratio(prices_list, fundamental, threshold=0.02) -> float` | `analysis-bases.md §2.5` |
| RuleLLM quality diagnostics | `fallback`, `fallback_type`, and `llm_attempts` fields in investor payloads | `analysis-bases.md §5` |

## §3 Analysis Dimensions

Analysis is performed by round, by agent type, by market phase, and by variant. The main comparison is whether RuleLLM preserves price deviation and mechanism intensity while changing the distribution of order flow relative to the deterministic baseline.

## §4 Variant-Specific Observable Phenomena

| Phenomenon | Description | How to Observe | Contrast with Baseline |
|---|---|---|---|
| Rule-clamped credit expansion | ProCyclicalLender reasons within ±20 % of the deterministic lending schedule; peak deviation stays near the Rule ceiling | `01_price_dynamics.png` peaks within ±10 % of Rule peaks; investor turn payloads' `reasoning` cites the leverage formula and confidence multiplier | LAI clusters tightly around Rule's LAI |
| Bounded Minsky trigger | MinskyBorrower must trigger inside a ±20 % window around the analytic distress threshold; cascade concentrates in 1-2 rounds | Sharp downslope in `02_cycle_dynamics.png` similar to Rule; `Credit Contraction Speed` within 15 % of Rule value | CCS within 15 % of Rule |
| Formula-consistent counter-cyclical activation | CounterCyclicalLender clamps LLM proposal to the deterministic offset schedule; CCOR σ across seeds is small | `summary.json → metrics.scenario_metrics.counter_cyclical_offset_ratio` σ ≤ 0.02 across 10 seeds | Variance intermediate between Rule and LLM |
| Reasoning-annotated bids with rule guardrails | Investor payloads contain `reasoning` fields but final bids equal `clamp(rule_bid ± 20 %)` | Cross-check payload `bid_price` vs analytic rule; `fallback_rate` from `summary.json → llm_diagnostics` ≤ 3 % | Fewer fallbacks than pure LLM |

RuleLLM combines the rule's deterministic backbone with LLM narrative colour; 10 independent trials remain required for Mann-Whitney U.

### Parameter Sensitivity (Variant-Specific)

| Parameter | Change | Expected Effect on This Variant's Analysis |
|---|---|---|
| Rule-clamp bound (±20 %) | +50 % (looser) | Metric variance grows; behaviour drifts toward LLM |
| Rule-clamp bound (±20 %) | −50 % (tighter) | Metrics collapse to Rule values; narrative becomes decorative |
| `MinskyBorrower.leverage_ratio` | +50 % | Higher MFS, tightly clustered around Rule's shifted value |
| `CounterCyclicalLender` population share | +50 % | Higher CCOR mean; low variance across seeds |

## §7 Cross-Variant Comparison Notes

RuleLLM is expected to be statistically indistinguishable from Rule on core metrics while adding interpretable reasoning traces (see `analysis-bases.md §5`).

| Comparison Axis | RuleLLM's Expected Position | Reason |

| Minsky Fragility Score | Near Rule | Distress trigger stays inside ±20 % of analytic threshold |
| Credit Contraction Speed | Near Rule | Bounded window preserves cascade concentration |
| Counter-Cyclical Offset Ratio | Near Rule mean; slightly higher σ | Clamp limits deviation; narrative introduces mild noise |
| Behavioral realism | Intermediate between Rule and LLM | Rule mechanics with human-readable rationale |
| Decision quality | Near-optimal | Guardrail keeps decisions inside rule-optimal band; reasoning aids interpretability |
