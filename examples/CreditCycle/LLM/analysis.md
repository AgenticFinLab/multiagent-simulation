# Credit Cycle LLM Analysis Plan

## §1 Objectives

This analysis checks whether the LLM variant produces a complete, analyzable Credit Cycle trajectory. It maps recorded price, fundamental, and volume series to the metric catalogue in `analysis-bases.md` and supports cross-variant comparison against the Rule baseline.

## §2 Core Metrics

| Metric | Function Contract | Source |
|---|---|---|
| Leverage Amplitude Index | `_compute_leverage_amplitude_index(peak, trough) -> float` | `analysis-bases.md §2.1` |
| Minsky Fragility Score | `_compute_minsky_fragility_score(investor_payloads, prices_list, fundamental, crisis_threshold=-0.05) -> float` | `analysis-bases.md §2.2` |
| Credit Contraction Speed | `_compute_credit_contraction_speed(prices_list) -> float` | `analysis-bases.md §2.3` |
| Counter-Cyclical Offset Ratio | `_compute_counter_cyclical_offset_ratio(investor_payloads, prices_list, fundamental, bust_threshold=-0.05) -> float` | `analysis-bases.md §2.4` |
| Phase Duration Ratio | `_compute_phase_duration_ratio(prices_list, fundamental, threshold=0.02) -> float` | `analysis-bases.md §2.5` |
| LLM quality diagnostics | `fallback`, `fallback_type`, and `llm_attempts` fields in investor payloads | `analysis-bases.md §5` |

## §3 Analysis Dimensions

Analysis is performed by round, by agent type, by market phase, and by variant. The main comparison is whether LLM preserves price deviation and mechanism intensity while changing the distribution of order flow relative to the deterministic baseline.

## §4 Variant-Specific Observable Phenomena

| Phenomenon | Description | How to Observe | Contrast with Baseline |
|---|---|---|---|
| Persona-driven credit expansion | ProCyclicalLender persona reasoning about "market momentum" and "confidence" drives boom lending; peak timing varies stochastically across seeds | `01_price_dynamics.png` peaks shift by ±3-5 rounds vs Rule; investor turn payloads' `reasoning` field cites narrative cues | Cycle onset later and softer than Rule |
| Diffuse Minsky trigger | MinskyBorrower personas hesitate at distress boundary; leverage unwinding spreads across several rounds instead of one | `02_cycle_dynamics.png` shows a gradual downslope rather than a cliff; `Credit Contraction Speed` in `summary.json` lower than Rule | CCS 20-40 % lower than Rule |
| Narrative counter-cyclical activation | CounterCyclicalLender persona sometimes defers buying while "waiting for confirmation"; CCOR variance across seeds is large | `summary.json → metrics.scenario_metrics.counter_cyclical_offset_ratio` shows σ ≥ 0.05 across 10 seeds | Higher variance than Rule (near-zero σ) |
| Fallback / parse-failure inflation | Occasional LLM parse failures reduce effective agent activity in high-volatility rounds | `investor_payloads[*].fallback` counts and `fallback_type` distribution in `summary.json → llm_diagnostics` | Fallback rate should stay ≤ 5 % for a valid run |

LLM introduces stochastic persona reasoning; 10 independent trials with distinct seeds are required for Mann-Whitney U comparison against Rule (`p < 0.05`).

## §5 Scaling and Sensitivity Analysis

### Round Scaling

| Total Rounds | Expected Observable | Phenomenon Clarity | Recommended for |
|---|---|---|---|
| 100 | 1-2 cycles; wide LAI variance | Low | Quick testing |
| 200 | 3-5 cycles; MFS/CCS estimates stabilize | Medium | Standard runs |
| 500 | Mann-Whitney U vs Rule reaches power ≥ 0.8 | High | Research quality |

### Agent Count Scaling

| Agent Count | Expected Observable | Environment Dynamics |
|---|---|---|
| 40 | Cycles noisier; fallback rate slightly higher due to shorter prompt context | Low order density; individual persona choices dominate variance |
| 100 | Clean phase separation; central limit smooths persona idiosyncrasy | Full boom-bust mechanism observable across seeds |

### Parameter Sensitivity (Variant-Specific)

| Parameter | Change | Expected Effect on This Variant's Analysis |
|---|---|---|
| LLM sampling `temperature` | +50 % | Higher CCOR variance; more fallback events; softer cycles |
| LLM sampling `temperature` | −50 % | Reasoning converges toward Rule-like behaviour; LAI/MFS trend upward |
| `MinskyBorrower.leverage_ratio` | +50 % | Higher MFS but with broader distribution than Rule |
| `CounterCyclicalLender` population share | +50 % | Higher CCOR mean; shallower troughs; larger cross-seed dispersion |

## §7 Cross-Variant Comparison Notes

LLM is compared against Rule via Mann-Whitney U on 10 independent trials (see `analysis-bases.md §5`).

| Comparison Axis | LLM's Expected Position | Reason |
|---|---|---|
| Leverage Amplitude Index | Lower than Rule | Persona hesitation caps expansion below threshold ceilings |
| Minsky Fragility Score | Lower than Rule | Distributed timing of leverage unwinding blunts concentration |
| Credit Contraction Speed | Slower than Rule | Persona narrative spreads deleveraging across rounds |
| Counter-Cyclical Offset Ratio | Similar mean, higher variance | CCOR fixed by population share but discretion adds noise |
| Behavioral realism | Higher than Rule | Persona reasoning mimics narrative-driven credit cycles |
| Decision quality | Lower than Rule for the specified thresholds | Fallbacks and hesitation deviate from analytic optimum |
