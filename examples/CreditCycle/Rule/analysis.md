# Credit Cycle Rule Analysis Plan

## §1 Objectives

This analysis checks whether the Rule variant produces a complete, analyzable Credit Cycle trajectory. It maps recorded price, fundamental, and volume series to the metric catalogue in `analysis-bases.md` and supports cross-variant comparison against the Rule baseline.

## §2 Core Metrics

| Metric | Function Contract | Source |
|---|---|---|
| Leverage Amplitude Index | `_compute_leverage_amplitude_index(peak, trough) -> float` | `analysis-bases.md §2.1` |
| Minsky Fragility Score | `_compute_minsky_fragility_score(investor_payloads, prices_list, fundamental, crisis_threshold=-0.05) -> float` | `analysis-bases.md §2.2` |
| Credit Contraction Speed | `_compute_credit_contraction_speed(prices_list) -> float` | `analysis-bases.md §2.3` |
| Counter-Cyclical Offset Ratio | `_compute_counter_cyclical_offset_ratio(investor_payloads, prices_list, fundamental, bust_threshold=-0.05) -> float` | `analysis-bases.md §2.4` |
| Phase Duration Ratio | `_compute_phase_duration_ratio(prices_list, fundamental, threshold=0.02) -> float` | `analysis-bases.md §2.5` |
| Noise/volatility diagnostics | `_compute_autocorrelation(prices_list)`, `_compute_peak_rolling_volatility(prices_list)` | `analysis-bases.md §2.6` |

## §3 Analysis Dimensions

Analysis is performed by round, by agent type, by market phase, and by variant. The main comparison is whether Rule preserves price deviation and mechanism intensity while changing the distribution of order flow relative to the deterministic baseline.

## §4 Variant-Specific Observable Phenomena

| Phenomenon | Description | How to Observe | Contrast with Baseline |
|---|---|---|---|
| Deterministic boom-bust rhythm | ProCyclicalLender expands credit above fundamental and MinskyBorrower ratchets leverage in lockstep; the peak-to-trough cycle length is a step function of `leverage_amplification` | `01_price_dynamics.png` shows repeating peaks/troughs at nearly identical spacing; `02_cycle_dynamics.png` phase bands align on integer round boundaries | This is the baseline |
| Threshold-locked contraction | Once cumulative deviation exceeds `distress_threshold`, deleveraging fires uniformly across leveraged agents in the same round | Sharp cliff in price series; `Credit Contraction Speed` in `summary.json` approaches its analytic maximum | This is the baseline |
| Counter-cyclical offset saturates | CounterCyclicalLender buys deterministically whenever `deviation < -bust_threshold`, so `Counter-Cyclical Offset Ratio` matches the closed-form share of counter-cyclical population | `summary.json → metrics.scenario_metrics.counter_cyclical_offset_ratio` clusters tightly around 0.5 across seeds | This is the baseline |
| Analytic Minsky fragility | MFS follows directly from `MinskyBorrower.leverage_ratio` and the size of the trigger cohort with no reasoning noise | `summary.json → metrics.scenario_metrics.minsky_fragility_score` reproducible to floating-point precision under fixed seed | This is the baseline |

Rule is the reference: transitions are threshold-driven, agent activity is fully explained by config parameters, and there is no LLM reasoning or retrieval variance.

## §5 Scaling and Sensitivity Analysis

### Round Scaling

| Total Rounds | Expected Observable | Phenomenon Clarity | Recommended for |
|---|---|---|---|
| 100 | 2-3 complete boom-bust cycles; PDR estimable | Low | Quick testing |
| 200 | 4-6 cycles; stable LAI / MFS / CCS estimates | Medium | Standard runs |
| 500 | Cross-seed statistical robustness on PDR and WRI | High | Research quality |

### Agent Count Scaling

| Agent Count | Expected Observable | Environment Dynamics |
|---|---|---|
| 40 | Cycles still visible; noisier NTC and WRI | Low order density; sparse counter-cyclical buffer |
| 100 | Clean phase separation; stable metric estimates | Full boom-bust mechanism observable |

### Parameter Sensitivity (Variant-Specific)

| Parameter | Change | Expected Effect on This Variant's Analysis |
|---|---|---|
| `ProCyclicalLender.leverage_amplification` | +50 % | Higher LAI, higher peak deviation, faster CCS on bust |
| `ProCyclicalLender.leverage_amplification` | −50 % | Muted LAI, shallower peaks, cycles may fail to complete |
| `MinskyBorrower.leverage_ratio` | +50 % | Higher MFS, deeper troughs, larger WRI |
| `CounterCyclicalLender` population share | +50 % | Higher CCOR, shallower troughs, PDR shifts toward stability |
| `NoiseTrader` population share | +50 % | Higher NTC, blurred phase boundaries |

## §7 Cross-Variant Comparison Notes

Rule is the reference variant against which LLM, RuleLLM, and Rag are compared (see `analysis-bases.md §5`).

| Comparison Axis | Rule's Expected Position | Reason |
|---|---|---|
| Leverage Amplitude Index | Highest | Threshold-driven expansion is uncapped by discretion |
| Minsky Fragility Score | Highest | Every leveraged agent triggers at the same boundary; no hesitation |
| Credit Contraction Speed | Fastest | Deterministic threshold crossing produces a step-function bust |
| Counter-Cyclical Offset Ratio | Mid | CCOR is fixed by population share, not reasoning |
| Wealth Redistribution Index | Highest | Losses concentrate on MinskyBorrower cohort without narrative smoothing |
| Behavioral realism | Mechanistically clean; behaviorally simplistic | Individual agents ignore reasoning, narrative, or retrieved context |
| Decision quality | Rule-optimal for the specified thresholds | Counter-cyclical buffer reacts deterministically once the bust threshold is crossed |
