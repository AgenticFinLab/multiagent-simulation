# Extracted Example Investors

This folder contains investor-agent profiles extracted from the repository's existing examples.

## Subfolders

- `unique/`: merged, deduplicated investor archetypes suitable for reuse across scenarios.
- `non-unique/`: original per-scenario extracted profiles, kept for traceability.

Use `unique/` when choosing an agent type for a new market. Use `non-unique/` when you need to inspect exactly how that agent appeared in a specific scenario.
