# 03 · 市场微观结构（领域层参考）

> 金融是“第一个参考领域”，不是平台内核。本文是使用者实现“市场”时的领域参考。

## 1. TwinMarket（微观 BDI + 宏观撮合 + 社交）

- 出处：NeurIPS 2025 / arXiv 2502.01506；ICLR 2025 Financial AI 最佳论文。
- 两层架构：
  - **微观层**：BDI（Belief–Desire–Intention）驱动用户行为——个性化策略、行为金融偏差（处置效应、彩票偏好）。
  - **宏观层**：订单驱动交易 + 社会信息交互 + **实时撮合引擎**。
- 关键点：社交网络（论坛式）、新闻/情绪、多维技术指标；复现“个体互动 → 群体狂热 → 宏观危机”。

### 对实现的启示（领域层，不进平台）
- 市场 = 挂在 `Topology` 上的 coordinator agent；订单簿/撮合 = 使用者用 `SharedState` 实现的领域规则。
- 行为金融偏差 = 使用者在 agent 决策里注入的领域逻辑（不是平台能力）。

## 2. MarketSim（战略/执行分层 + CDA）

- 出处：ICML 2026（poster 65297）。
- 做到了：15,000+ 异质参与者；**战略层（AI 基金经理，LLM 慢决策）与执行层（交易员 agent，高频快执行）解耦**；纳秒级 NASDAQ 式连续双边拍卖（CDA）；接入 12k 新闻/政策/财报；复现 5 个 stylized facts，平均 MAPE 3.48%。

### 对实现的启示
- “战略/执行分层”是金融场景“LLM 慢、市场快”的标准答案——**这正是我们 Scheduler 里“低频决策 + 高频执行”的领域实例**。
- stylized facts + 价格统计指标 = 领域评估基准（见 `09`）。

## 3. 领域层与平台内核的边界（重点）

| 能力 | 归属 |
|------|------|
| 订单簿、撮合、行情 | 领域层（使用者实现，用 SharedState + coordinator agent） |
| 金融 agent 策略/偏差 | 领域层 |
| 金融指标/stylized facts | 领域层（评估） |
| 时间/激活/消息/状态/拓扑 | 平台内核 |

> 关键：平台内核不出现“订单/价格/撮合”字样；它们只出现在领域实现里。
