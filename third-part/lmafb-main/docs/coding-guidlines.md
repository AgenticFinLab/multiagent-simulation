### Guidance for Coding of llmgt Package

> The llmgt package is designed to facilitate the flexible setup and execution of multi-agent simulations in environments involving multiple large language models (LLMs). The package allows users to define, configure, and manage agents, each with their own settings, roles, and interactions within a system. The goal of this guide is to provide detailed instructions on how to set up and utilize the llmgt package, ensuring that users can efficiently create and run multi-agent simulations tailored to their needs.
